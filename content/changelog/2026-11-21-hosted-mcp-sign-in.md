---
title: Hosted agents such as Nebula sign in to MergeLoop with GitHub
kind: improved
---

MCP clients that run on the web, such as Nebula and claude.ai, can now connect to `https://mergeloop.ai/mcp` through the same GitHub sign-in that Claude Code and Cursor use. They no longer need a personal access token. Before MergeLoop sends anything back, its consent page names the site the sign-in goes to, so you can deny one you didn't start.
